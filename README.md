# SSAFY ALGO

SSAFY 16기 알고리즘 스터디의 문제와 풀이를 확인하는 웹 대시보드입니다.

## 링크

- [SSAFY ALGO](https://algo-study-agent.vercel.app/)
- [스터디 Notion](https://app.notion.com/p/3c5a717ec99e80e3b24df528768d2ce1)
- [코드 저장소](https://github.com/ssafy-16th-algorithm/algo-study-agent)

## 기능

- Notion의 주차별 문제와 풀이 동기화
- 풀이, 시도한 풀이, 전략, 후기 표시
- 기본 LLM 모델 호출량 초과 시, 대체 모델로 fallback
- AI 리뷰 일시 오류 자동 재시도, 대기시간 안내 및 요청 시간 제한
- Notion 풀이가 없을 때 GitHub 코드 조회
- Java 코드 문법 강조
- 멤버별 주차 진행도 표시
- 마감 당일 및 마감 이후 미완료 문제 알림
- 버튼으로 요청하는 AI 코드 리뷰
- 100점 만점 코드 평가, 항목별 점수·근거, S~D 등급과 다음 등급 목표
- 라이트·다크 모드와 반응형 화면

## AI 점수 기준

AI 리뷰는 **GPT → Ollama → Groq** 순서로 설정된 제공자를 호출합니다. 오류 또는 잘못된 리뷰 응답이 발생하면 다음 제공자로 넘어갑니다.
프로젝트 루트의 `.env.local`에 `OPEN_AI_API_KEY`로 GMS Key를 설정하면 GPT가 1순위로 활성화됩니다. 키는 서버에서만 Bearer 토큰으로 사용합니다.
`OPEN_AI_REVIEW_MODEL`의 기본값은 `gpt-5.4-mini`, `OPEN_AI_BASE_URL`의 기본값은 `https://gms.ssafy.io/gmsapi/api.openai.com/v1`입니다.
GMS의 `/chat/completions`로 요청합니다. 다른 OpenAI 호환 서버를 사용하려면 해당 서버의 기본 URL과 지원 모델명을 두 변수에 지정하세요.
기존 `OLLAMA_API_KEY` / `OLLAMA_REVIEW_MODEL`, `LLM_API_KEY` / `LLM_REVIEW_MODEL`은 대체 제공자 설정으로 유지됩니다.
환경변수를 바꾼 뒤 개발 서버를 재시작하고, 배포 환경에도 동일하게 등록하세요.

| 항목 | 배점 | 평가 내용 |
| --- | ---: | --- |
| 정답성 | 40 | 문제 요구사항, 로직, 경계값 처리 |
| 시간·공간 효율 | 30 | 시간·공간 복잡도, 불필요한 연산과 저장 |
| 구현 안정성 | 20 | 인덱스, 자료형, 초기화, 상태 복구 |
| 가독성 | 10 | 의미 있는 이름, 구조, 중복 제거 |

등급은 S 90~100점, A 80~89점, B 70~79점, C 60~69점, D 0~59점입니다. 확인된 문제의 영향을 기준으로 평가하고 같은 결함의 중복 감점을 피하도록 지시합니다. 이 점수는 **코드를 실행하지 않은 AI의 분석 결과**로, 실제 채점 점수나 확정된 순위가 아닙니다. 같은 문제·같은 기준에서 개선 방향을 비교하는 용도로 사용하며, 모델·재요청에 따라 점수가 달라질 수 있습니다.

- 항목별 점수는 배점 내 정수와 근거가 있어야 인정하며, 총점·등급은 서버에서 계산. 점수가 누락되거나 잘못된 AI 응답은 기존 fallback·재시도 흐름으로 복구
- 점수 도입 전 리뷰 캐시와 구분하도록 리뷰 버전을 갱신하고, 점수 근거를 포함할 수 있도록 모델 출력 한도 조정
- AI 리뷰 429·502·연결 오류 자동 복구 추가: 최초 요청 뒤 최대 2회 재시도하며, 매 요청에서 Ollama → Groq 순서로 전환
- `Retry-After`의 초·HTTP 날짜 형식을 준수하고, 기본 2초·4초 대기에 작은 무작위 지연을 더해 재시도. 모델별 15초, 브라우저 API 요청별 45초 시간 제한 적용
- 30초를 넘는 대기, 앱 자체 시간당 요청 제한, 인증·입력·설정 오류는 자동 재시도를 중단하고 안내. 대기시간이 남아 있으면 수동 요청 버튼도 비활성화
- 재시도 횟수와 남은 시간 표시, 기존 리뷰 유지, 멤버·코드 변경 및 페이지 이탈 시 요청 취소
- ‘최소 수정 예시’ 표시를 ‘수정 예시’로 변경
- 정주연·박지우를 스터디원에 추가해 총 6명의 Notion 풀이, 시도한 풀이, 전략, 후기를 조회하고 AI 코드 리뷰를 요청할 수 있도록 연결
- 정주연·박지우는 8주차부터 합류: 홈 스터디원·진행도·미완료 알림·로딩 카드에 8주차부터 포함 (1~7주차 4명, 8주차 이후 6명)
- 주차 전환 시 이전 주차의 진행도 카드가 남지 않도록 선택 주차와 응답 주차를 일치시켜 표시
- 코드 연결 인원을 실제 멤버 수로 표시하고, 6명에 맞춰 멤버 탭·진행도 카드·로딩 화면 배치 조정
- GitHub 저장소가 미등록된 멤버는 Notion만 조회하며, 풀이 페이지가 없는 문제에서는 원본 문제 페이지로 연결
